The impostorPop class includes screen-cell light events assigned to a GPU traffic source with no detected tower occlusion. Light pixels use fixed luminance thresholds: 170 for entry and 60 for exit. The pop detector uses 4×4 CSS-pixel cells. Its motion search covers 3 cells, or 12 CSS pixels. Source attribution uses a 10 CSS-pixel radius. PROOF_DPR sets the requested browser DPR. The output records the actual drawing buffer and renderer size. Physical-pixel filtering still follows the drawing buffer. The detector saves raw events. Pixel aliasing, other occluders, and source matching can affect counts. A nonzero count requires inspection. Nearest-source attribution can select a faded GPU instance. It does not prove actual source-ID support. Use the frozen classification pass for the stricter visibility check.

The road check measures traffic trail length and width. Review the saved top views for road shapes. The script does not replace that review.

Frame metrics exclude the HUD. Neon pixels have saturation at least 0.35 and maximum channel at least 0.45. Hue bins span 30 degrees. Keep these settings fixed in all comparisons.

Frozen light classification

node tools/render-evidence/classify-lights.cjs BEFORE_URL BEFORE_DIR
node tools/render-evidence/classify-lights.cjs AFTER_URL AFTER_DIR BEFORE_DIR/classification.json

This tool uses headless Chromium with ANGLE Metal. Set PLAYWRIGHT_MODULE to an installed Playwright module. The browser closes after the check. No package change is required.

The tool pauses the clock before page load. It captures high tier at 8.2, 24, and 40 seconds. It captures low tier at 8.2 seconds. Each capture uses a new page. It sets only the frozen presentation tick, at 30 ticks per second. The after capture first matches the simulation tick and interpolation phase from the before JSON. It then uses the before camera. The JSON records camera and time differences. The simulation stays unchanged.

The detector uses maximum Rec.709 code luma in each 4×4 pixel cell. HI is 170. LO is 60. A small cluster has at most 8 HI cells and 64 LO cells. Its 5×5 local block has at most 8 HI cells. The audit excludes the left 10%, right 12%, and top and bottom 10%. Larger clusters have separate records and dashed boxes. These settings measure bright small blobs. They do not count all cars.

The full frame has a matching traffic layer. This layer keeps opaque depth occluders. It hides other emission. Separate CPU and GPU source-ID passes use the actual sprite vertex shaders, path texture, uniforms, capsule support, and depth tests. They omit fog brightness and bloom. A candidate must have source-ID support at a bright pixel in the real traffic layer. The nearest projected valid candidate supplies the source class. GPU attributes and rows must match the seeded diagnostic data exactly. A mismatch fails the check.

CPU lamp positions come from aCarPos, aCarDir, and aCarFade. A CPU source has a hull only if its position matches a visible instance matrix, the matrix scale is nonzero, and its distance is at most 1300 metres. Matrix matching proves that body geometry is drawn. It does not prove visible hull color at every light pixel. Active CPU fade records include the maximum distance and the matched hull. Low tier far CPU lights have a separate allowed class.

GPU classes identify existing stream, lane, and ring paths. They do not prove a physical CPU counterpart for each GPU car. Two valid source groups in one cluster remain ambiguous. A source-ID pass can hide an earlier ID at complete overlap. A blob without valid support stays unknown. Full-only blobs stay unknown. They can contain sign light, a hull lamp patch, or an unresolved blend. The audit does not force these records into a GPU class.

The output includes full frames, traffic layers, source-ID images, colored coordinate audits, shader hashes, adapter logs, and classification.json. proof.html contains the visual audit. Browser errors or GL errors produce a nonzero exit code. Inspect unknown and ambiguous records before a conclusion.

GPU route parity

R21_GPU_COUNT=20000 R21_GPU_PROGRESS_EXPR=canyonArcM node tools/render-evidence/gpu-parity.cjs URL OUTDIR

The tool reads the actual compiled vertex shader, uploaded path texture, uniforms, and instance attributes. Transform feedback records world positions before camera-facing geometry and fading. It compares each position with the diagnostic evaluator. This check does not prove fragment visibility or frame cost. Set PLAYWRIGHT_MODULE to an installed module. The browser closes after the check.

Interior silhouette experiment

This experiment changes only cached diagnostic materials. It does not change the game default. It keeps the original furniture trace and distance weights. It adds a cheap room silhouette at offsets of 150, 300, and 450 metres. Offset 0 selects the original material.

node tools/render-evidence/interior-silhouette-ladder.cjs --url URL --out OUTPUT --installer tools/render-evidence/interior-installer.cjs --samples 24 --draw-only true --rebuilt-zero true
node tools/render-evidence/interior-silhouette-capture.cjs --url URL --out OUTPUT --installer tools/render-evidence/interior-installer.cjs
node tools/render-evidence/interior-silhouette-values.cjs --url URL --out OUTPUT --installer tools/render-evidence/interior-installer.cjs

Use a built high-tier page with 20,000 impostors. The tools use DPR 1.25 and a 1280 by 720 CSS viewport. They use a shared GPU lock. Run one GPU check at a time. They close the browser after each check.

The timer check uses frozen views at route positions 2400, 2800, and 3200 metres. It warms each shader. It uses paired ABBA samples. With draw-only true, the tower timer covers the actual GL draw call. The full-frame timer includes CPU submission gaps. It is not a sum of draw costs or a full-lap timing proof. The rebuilt-zero control measures the cost of the extra shader code with the new stage inactive.

The image check records direct-render zero-offset parity with identical source uniforms. It also records play views and an isolated actual facade. Other mesh objects, volume fog, and bloom are disabled in the facade check. Full play frames keep the production post chain. The value check records all four offsets on the standard six-frame series.

The installer checks exact live source anchors. It fails if the source does not match. It copies live material flags and shares current uniforms. It restores the original material after the check. Source equality does not guarantee equal compiled pixels. Inspect the parity images. Partial screen selections can change brightness and final hue in this prototype. Measure those effects before a production change.
