Buggy recovery from fallen barrels

The centered barrel case used the actual chassis and hazard drum shapes.
The buggy rested on its belly. All four wheel rays ended above the floor.
The SDK applied no tire force. Contact points were inside the chassis.
A simple box chassis had the same result. This case was low ground clearance.

The game now uses a 0.9 m suspension rest length instead of 0.5 m.
Suspension damping is doubled. Drive force is 13.5 times chassis mass instead
of 18 times mass. Spawn height is 0.4 m higher. The visible wheels and new
suspension links use the same wheel state as physics.
No force or velocity edit is added to airborne driving.

Evidence on Syncplay 6.0.0-rc.40:
- 36 barrel drop cases cover both barrel axes, nine offsets, and voxel or
  box chassis shapes. Each escapes forward and reverse in 120 ticks.
- Minimum travel is 1.085809 m. All 36 checkpoint repeats match.
- Centered voxel cases travel at least 17 m in each direction.
- No airborne tire-force tick occurs.
- Maximum barrel speed is 2.6246 m/s in the tested cases.
- The ramp takes off, lands, and stops. Existing test limits are unchanged.
- All 317 tests pass in 51 files. TypeScript passes.

Repeat the SDK fixture:
node scripts/repro-syncplay-buggy-barrel.mjs --variant=rest-09-drive-075-damp-2 --rest=.9 --drive-scale=.75 --damping-scale=2 --assert-recovery
