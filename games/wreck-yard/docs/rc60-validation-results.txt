New checkpoint and canonical probes
-----------------------------------

The discarded-future checkpoint probe uses 270 bodies, 16 colliding
boxes and compound floor geometry. It captures frame 12, runs a common
60-frame future, then repeats after compact-contact and far-separated
discarded futures. Every frame's public motion, latest contacts, digest
and serialized bytes match within each release. The retained checkpoint
bytes remain unchanged. rc.59 and rc.60 both pass and dispose to zero.
This tests history independence. It does not prove an internal broadphase
branch ran or prove continuation across SDK versions.

The canonical/wire probe passes 30 checks across both releases. It covers
Unicode, lone surrogates, offset byte/DataView inputs, empty byte views, special
numbers, Map, Set, invalid tags, invalid protocol/version/kind and checksum
tampering. Explicit expected canonical trees and an independent UTF-16 FNV
checksum oracle verify exact wire bytes. Every valid message cross-decodes.
Inputs remain unchanged. All malformed cases fail closed without throwing.
The probe uses public function names through implementation files. New
internal helpers are not invoked. It does not test hostile getters,
reentrant serialization, donor selection, or browser timing.

Source limits and remaining requests
------------------------------------

rc.60 allows active proxies in the small/large special-path predicates.
It adds primitive-cylinder contact iterations up to 12 when configured
iterations are 2 through 11. Compound-parent cylinders and a configured
single iteration are outside that filter. Grow-on-write buffers retain
logical limits. Unchanged-geometry restore can keep broadphase state.
Bullet traversal retains work-quota charges. Source alone does not prove
portal stability, all shape combinations, or a torch speed gain.

Snapshot versions, public physics declarations, authority, runner, seat,
retention, explicit leave and donor recovery match rc.59. Canonical v2
checksums reuse canonical JSON when it is a fixed point. The public wire
format is unchanged. New fixed-point helpers are internal, not new root
or browser exports. Existing public app calls need no migration.

The confirmation loop still has no per-call work/time cap. Missing-target
donor refusal and rotation need a focused real protocol test. Ordinary
successful transfer does not cover those branches. Production close-to-kick
source exists at the rc.59 release commit. Hosted deployment and socket-loss
grace remain outside this local campaign. No deployment was made.
