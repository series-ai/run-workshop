2. Browser and torch performance.

All six serial Chrome/WebKit cases pass. CPU slowdown recovery gives
9.126 m movement on both peers. Both runners are live with backlog 0 by
the first neutral check requested two seconds after clear. This is not
an exact latency or worst-case work bound. TouchCancel clears the held
joystick axes and simulation frames continue. Scale remains 1.

Local aged-room leave/rejoin takes 130/1102 ms. Normal leave/rejoin takes
218/469 ms. Snapshot transfers at 3480 and 3600 decode. No unavailable
refusal or failed-donor rotation occurs. Two resource 404 entries are
attributed to the app's /favicon.ico. Page and wire errors are empty.
These desktop tests do not establish physical-iPhone or RUN-app behavior.

The single touch-driven storage torch route passes six functional checks
and ten segments. It still does not return to idle cost after 60 seconds:

  Idle            60.08        2.60                        2

Input is neutral. Cuts stop at 14. Fractures increase from 2 to 3 after
release. Native bodies increase 703 to 706; render bodies 550 to 553.
No functional, page, shader or session errors occur. rc.59 ended near
52 Hz with 18 cuts and 17 fractures, so this is not a controlled solver
speed comparison. The newer route ends near 58 Hz, but active workload
and native cost remain far above idle. Isolate active islands, contact
wake propagation, and the game's continuing wake/fracture policy before
assigning the cause. Supply an engine repro and repair for any SDK cause.
Native timing includes output work. No phone was measured.

3. Supply measured mobile history settings and recovery bounds.

Four-player history still peaks at 174.93 MiB of raw JS physics buffers,
with 22.37 MiB native retained high-water. Metrics overlap. Old-state
replay and zero-owned-resource cleanup pass. Both stable and busy runner
drives retain 256 logical saves and at most 32 native saves at frame 600.
Default exported byte history remains large. This is not a leak claim.

Seat context and retention APIs already exist. Wreck Yard must adopt an
explicit supported policy. Give tested snapshotBufferSize,
maxInputRetentionFrames, checksumCadenceTicks, maxSnapshotBytes and
minimumSnapshotWitnesses values. Test rollback, late join, donation,
long-session retention and replay export together. Measure a phone.

The confirmation loop still has no per-call work/time cap. Add or document
bounded recovery work. Keep the existing slow-client regression tests.
Missing exact-target donor refusal and rotation still need a focused real
protocol test. A normal successful transfer does not cover that branch.

4. Verify the hosted intentional-leave repair is deployed.

The client close signal and local authority removal exist. Production
close-to-kick source exists at the rc.59 release commit. Identify the
deployed server version. Verify hosted explicit leave, repeated close,
and unexpected socket loss with reconnect grace. No hosted test was made
in this local campaign. Keep the intended seat reservation policy.
