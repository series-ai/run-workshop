Cause and fix

Three.js caches values from constant animation tracks. It did not write zero again after the game added an opening. The added shape could remain. The runtime now restores the previous authored values before each mixer update, captures the new authored values, then applies the temporary changes.

Tests use the actual Three.js animation mixer. They check a constant closed mouth, a released grip, and a full source scream. The full source scream retains weight 1. No source clips, bone poses, or model files were changed.
