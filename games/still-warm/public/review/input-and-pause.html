One input at a time.

Checked in Chromium on 7 September 2026. Sound remained off.

Voice to text

Hold Space, then press Enter before releasing it. The text field opens. Before the fix, a late voice result could still send an instruction. The keyboard switch now cancels the recording.

Check Observed result
Late voice result before the fix One unwanted command reached the controller.
Late voice result after the fix No command reached the controller. The text field stayed open.
Submit the typed instruction One command reached the controller.
Compact text view The form fits a 390 × 460 viewport. No horizontal overflow.

This check used the real App and VoiceInput code. Browser recognition was replaced with a controlled test object. The old callbacks were saved before cancellation and invoked after it. Controller commands were recorded instead of sent to a model. This checks the input boundary; it does not measure speech recognition quality.

Paused scene state

A controlled browser session also tested a request that never returned, even after abort. The controller retired it after three seconds. Continue opened a second session. The same GameStore and Gentle hands rule remained. The second typed instruction reached the replacement session. Sound stayed off. This used a stalled test transport, not a forced outage of the RUN service.

Pause, connection, and ending dialogs now keep keyboard focus inside their controls. Continue receives focus first. Twelve Tab presses stayed within the pause menu. Shift-Tab from Continue reached the last control. Opening Standing rules made its controls available in the same order.

A lit scene can now start paused with the correct light levels and lamp aim. The door bars also start in their stored or locked pose. Dust, flame, door motion, and fallback body motion keep their phase during pause.
