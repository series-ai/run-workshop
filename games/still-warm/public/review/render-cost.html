The cost of the cellar.

These measurements use the actual lit room and approved model. No production render setting or asset was changed after this audit.

Scene sample Draw calls Triangles
Desktop, shadows on 559 3,697,547
Desktop, shadows off for measurement 172–173 528,791–528,803
Mobile, shadows on 506 3,696,153
Mobile, shadows off for measurement 119 527,397

Shadow passes add 387 draw calls and 3,168,756 triangles. This is about 86% of the drawn triangles. The room uses a point-light shadow and a spot-light shadow, both at 1024 pixels. The point light has six shadow faces.

Mobile pixel density

The default pixel ratio reaches 2 on a high-density screen. The measured mobile canvas had a 390 × 658 CSS size and a 780 × 1316 drawing buffer. Ratio 1 uses one quarter as many buffer pixels. These paused images compare the same view.

Limits

Counts came from Three.js renderer.info in headless Chromium. They do not measure frame rate on a phone. The separate shadow-light comparison was not completed before the work window ended. The current shadow setup and default pixel ratio remain in the game.
