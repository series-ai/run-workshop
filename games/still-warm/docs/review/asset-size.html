Creature asset size review

Decision: Keep the current asset. No asset files changed.

Measured file

public/assets/creature.glb is 18,237,188 bytes. The file uses Draco for the base mesh. The three position morph accessors already use glTF sparse accessors.

Lossless sparse check

The three normal morph accessors have 47,149, 45,832, and 43,958 exact-zero elements. A temporary sparse reconstruction matched every decoded Float32 byte. Each candidate needs 32-bit sparse indices because its data reaches vertex 297,171. The candidate adds about 1.38 MB to the raw file and about 0.92 MB at gzip level 9.

The asset keeps all three morph targets and all nine animation clips. It has no tangent morph targets. Three.js 0.170.0 supports sparse accessors, but sparse normals require extra load-time copying and memory.

Verification record

The audit parsed the GLB JSON and binary chunks. It rebuilt each normal accessor from sparse indices and values, then compared the decoded bytes. The candidate was temporary and was not copied into the project.
